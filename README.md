# AI Governance Control Validation Lab

## Project Overview

This project demonstrates the development and validation of an AI governance and security control program for a fictional healthcare technology company, Meridian Health Solutions.

The objective is to identify AI-related security risks, map applicable security controls, develop validation procedures, evaluate control effectiveness, and document remediation recommendations.

## Business Scenario

Meridian Health Solutions is a fictional healthcare technology company with approximately 250 employees.

The organization uses generative AI tools to support daily business operations but lacks a formal AI governance and control validation program.

Potential risks include:

- Unauthorized use of AI applications.
- Exposure of sensitive information through AI prompts.
- Inadequate access controls.
- Lack of third-party AI vendor assessments.
- Insufficient monitoring and oversight of AI usage.

## Project Objectives

1. Develop an AI governance risk register.
2. Map AI-related risks to applicable security controls.
3. Develop control validation procedures.
4. Execute controlled security tests using synthetic data.
5. Document test results and supporting evidence.
6. Identify control gaps and recommend remediation.

## Frameworks and References

- NIST AI Risk Management Framework (AI RMF).
- NIST SP 800-53 Rev. 5.
- NIST Privacy Framework.
- ISO/IEC 42001.

## Project Deliverables

- AI governance risk register.
- Security control matrix.
- Control validation test cases.
- Test results and evidence.
- Findings and remediation plan.
- Final governance assessment report.
